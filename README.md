## MODULAR · Funktion

MODULAR ist wie es läuft.

- **3 zu 1:** 3 Dateien → 1 Modul. Nicht 1 zu 1.
    - `pc + gpu + formen → hardware.py`
    - `axiome + evo + markt → lauf.py`
    - `index + final → home.py`
- **6D:** `X WAS, Y WIE, Z WO, Q QUELLE, D DRIFT, F FAKTOR`
- **ANKER:** `CORE 81.rom + SCAN 81.scan + TMP 81.tmp + VIDEO 81.video`
- **SCAN:** `LOAD 6 → SYNC TRUE → STATE READY`
- **Wenn weg, dann weg sagen.**
- **Am Ende immer:** `ECO + FUNKTION` — das ist Musik.

Funktion heißt: Jede Datei weiß, was sie tut. Jede sagt am Ende, was sie getan hat.
Kein toter Knopf. Kein stummer Lauf.
